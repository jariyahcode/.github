# Panduan Kontribusi JariyahCode 🤝

**Baca dalam:** [English](CONTRIBUTING.md) | [Bahasa Indonesia](CONTRIBUTING.id.md)

Terima kasih banyak sudah meluangkan waktu untuk berkontribusi di JariyahCode! Setiap baris kode yang Anda tulis adalah kontribusi nyata untuk umat, dan semoga menjadi ladang pahala jariyah bagi kita semua.

Agar kolaborasi kita berjalan lancar, rapi, dan berkah, mohon ikuti panduan kontribusi di bawah ini.

---

## 📜 Aturan Dasar (Code of Conduct)

1. **Niatkan karena Ibadah:** Kita bergerak secara sukarela demi kemaslahatan umat. Jauhkan ego pribadi dan perdebatan yang tidak produktif.
2. **Saling Menghargai:** Komunitas ini terbuka untuk semua tingkat keahlian (*Junior hingga Senior*). Berikan masukan yang membangun saat melakukan *Code Review*.
3. **Open Source & Gratis:** Semua kode yang Anda kirimkan otomatis akan dilepas menggunakan lisensi MIT (Terbuka dan Gratis untuk Umat).

---

## 🛠 Alur Kerja Kontribusi (Git Workflow)

Kami menggunakan alur kerja berbasis *Fork & Pull Request*:

### 1. Cari atau Buat "Issue"
* Buka tab **Issues** di repositori. Cari tugas yang belum dikerjakan. Jika baru, cari label `good first issue`.
* Berikan komentar di *issue* tersebut untuk menyatakan ketertarikan Anda.
* Jika menemukan *bug* atau ide baru, buatlah *issue* terlebih dahulu.

### 2. Fork & Clone
* Klik tombol **Fork** di pojok kanan atas untuk menyalin proyek ke akun Anda.
* Clone ke laptop Anda: `git clone https://github.com/USERNAME_ANDA/nama-repositori.git`

### 3. Buat Branch Baru
* Jangan gunakan branch `main`. Gunakan branch yang deskriptif:
  `git checkout -b feature/nama-fitur` atau `git checkout -b bugfix/nama-bug`

### 4. Commit & Push
* Tulis pesan *commit* yang jelas: `git commit -m "feat: integrasi API jadwal shalat"`
* Push ke fork Anda: `git push origin nama-branch-anda`

### 5. Kirim Pull Request (PR)
* Buka repositori **JariyahCode**, klik **Compare & Pull Request**. Tim akan meninjau kode Anda sebelum digabungkan.

---

## 🎨 Standar Penulisan Kode

* **Nama Variabel Jelas:** Gunakan nama deskriptif (contoh: `totalMasjid` bukan `x`).
* **Dokumentasi:** Berikan komentar pada logika yang kompleks.
* **Keep It Simple:** Tulis kode yang sederhana dan mudah dirawat.
