
# Contributing to JariyahCode 🤝

**Read in:** [English](CONTRIBUTING.md) | [Bahasa Indonesia](CONTRIBUTING.id.md)

Thank you for your interest in contributing to JariyahCode! Every line of code you write is a real contribution to the Ummah, and we hope it serves as a continuous charity (Sadaqah Jariyah) for all of us.

To ensure our collaboration remains organized, efficient, and blessed, please follow these contribution guidelines.

---


## 📜 Code of Conduct

1. **Intention (Niat):** This is a volunteer-based community for the benefit of the Muslim Ummah. Please maintain a positive attitude and avoid unproductive debates.
2. **Respect:** This community is open to all skill levels (Junior to Senior). Provide constructive feedback during Code Reviews.
3. **Open Source & Free:** All code submitted will be released under the MIT License (Open and free for the Ummah).

---

## 🛠 Git Workflow

We use a "Fork & Pull Request" workflow:

### 1. Find or Create an Issue
* Check the **Issues** tab. Find an unassigned task. If you are new, look for the `good first issue` label.
* Comment "I would like to work on this" to get assigned.
* For bugs or new feature ideas, create a new issue first.

### 2. Fork & Clone
* Click the **Fork** button to copy the project to your own account.
* Clone it: `git clone https://github.com/YOUR_USERNAME/jariyahcode-repo.git`

### 3. Create a Branch
* Never work directly on `main`. Create a descriptive branch:
  `git checkout -b feature/your-feature-name` or `git checkout -b bugfix/your-bug-name`

### 4. Commit & Push
* Commit with a clear message: `git commit -m "feat: integrate prayer times API"`
* Push to your fork: `git push origin feature/your-feature-name`

### 5. Pull Request (PR)
* Open the original **JariyahCode** repository and click **Compare & Pull Request**.
* We will review your code before merging it into the main project.

---

## 🎨 Coding Standards

* **Clear Naming:** Use descriptive variable names (e.g., `totalMosques` instead of `x`).
* **Documentation:** Comment on complex functions/logic.
* **Keep It Simple:** Prioritize clean, efficient, and maintainable code.

---

## 💬 Need Help?

If you are stuck, feel free to:
* Ask in the GitHub **Issues** or **Discussions** tab.
* Join our Discord in the `#diskusi-tech` channel.

Happy coding and may your efforts be a Sadaqah Jariyah! 🚀
